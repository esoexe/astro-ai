# Founder Pack

11 skills that test a business before you launch it: board review, CFO unit economics, pricing, offer, competitors, consumer interviews, brand, marketing, ops, plan and launch.

Adapted from [founder-skill](https://github.com/Jakeschincariol/founder-skill) by Jake Schincariol (MIT). See NOTICE.md.
