# Replica Pack

11 skills that study an app's features and help you build your OWN original product in that space: recon, architecture, design tokens with contrast checks, build, backend, tests, visual diff, deploy and launch.

> **Read first.** Build an original product. Do not copy another company's name, logo, artwork, text, code or private APIs, and respect trademarks, copyright and terms of service. The brand sweep exists to make sure nothing of theirs ships.

Adapted from [replica-skill](https://github.com/Jakeschincariol/replica-skill) by Jake Schincariol (MIT). See NOTICE.md.
