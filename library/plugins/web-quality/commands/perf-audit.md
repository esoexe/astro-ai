---
description: Measure and improve the loading and runtime performance of a web page or app.
---
Measure first. Build the app the way it ships, then check bundle sizes, images, fonts, render-blocking resources, layout shift and long tasks for $ARGUMENTS (or the home page). Use Lighthouse or a browser MCP server for real numbers when available. Report the baseline, the three biggest problems with fixes, and the numbers after any change you make.
