# Instagram Pack

13 skills for Instagram: reels with hook scoring and beats, captions, carousels, stories, comments, DMs, replies, profile audit, repurposing, a plain-voice style editor and a weekly plan.

Adapted from [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) by Jake Schincariol (MIT). See NOTICE.md.

## Use

Ask the agent for the job in plain words ("write chapters for this transcript"), or name the skill.
Some skills run helper tools that are built into A.S.T.R.O AI (1.9.0 or later); nothing extra to install.
