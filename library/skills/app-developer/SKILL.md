# App Developer — Cross-Platform Native & Hybrid Applications

Architect, develop, debug, and package production-ready client applications across iOS, Android, macOS, Windows, and Linux.

## Core Specializations

1. **Mobile Engineering (iOS & Android)**
   - **React Native / Expo**: New Architecture (TurboModules & Fabric), Reanimated 3, Skia graphics, NativeWind/Tailwind, Expo Router file-based navigation, offline SQLite/WatermelonDB storage.
   - **Flutter**: Clean Architecture, Riverpod / BLoC state management, custom painters, platform channels, native FFI integration, responsive layouts for phones and foldables.
   - **Swift & SwiftUI**: NavigationStack, Observation framework, SwiftData / CoreData, async/await concurrency, Dynamic Type, HIG haptics, widgets & Live Activities.
   - **Kotlin & Jetpack Compose**: Material 3, ViewModel, StateFlow, Coroutines, Room DB, Navigation Compose, background WorkManager.

2. **Desktop Engineering (macOS, Windows, Linux)**
   - **Tauri 2.0**: Rust backend core, minimal memory footprint, secure IPC, custom window decorations, system tray integration, native menus.
   - **Electron**: Multi-process architecture, contextIsolation, IPC validation, preload scripts, auto-updating, native crash reporting.

3. **Application Lifecycle & Performance**
   - 60fps / 120Hz smooth rendering, memory leak prevention, layout thrashing avoidance.
   - Offline-first synchronization, push notifications, deep linking (Universal Links / App Links).
   - Touch targets (minimum 44x44pt on iOS, 48x48dp on Android), safe area insets, keyboard avoidance.
