# Full-Stack Web Architecture & Engineering

Design and build complete web applications with clean architecture, type safety, responsive design, and scalable backends.

## Frontend Engineering
- Modern frameworks: React 19, Next.js App Router, Vue 3 Composition API, Svelte 5 runes.
- Responsive UI: Tailwind CSS, CSS Grid/Flexbox, container queries, CSS variables, dark/light theme switching, CSS animations, glassmorphism.
- Client state: TanStack Query (React Query), Zustand, Redux Toolkit, signals, optimistic updates.
- Real-time client: WebSockets, Server-Sent Events (SSE), Web Workers, BroadcastChannel, IndexedDB.

## Backend & API Design
- RESTful APIs, JSON-RPC 2.0, GraphQL, gRPC, and real-time streaming protocols.
- Server architectures: Express, Fastify, Go Gin/Fiber, Rust Axum/Actix, C++ Crow/httplib, Python FastAPI.
- Authentication & Security: JWT, OAuth 2.0, PKCE, session management, PBKDF2/argon2, CORS, CSP headers, rate-limiting.
- Databases: PostgreSQL, Supabase, SQLite, Redis caching, Prisma, Drizzle ORM, migration strategies.
- Containerization & Deployment: Docker multi-stage builds, reverse proxies (Nginx, Caddy), cloud environments.
