A.S.T.R.O AI Library data

This site hosts the community catalog used by A.S.T.R.O AI: MCP servers, Agent Skills, plugins and AI tools from public sources.

Browse and install it in the app (Extensions → Library) or in the website Console. The data files are under v3/; the format is described in web/lib3core.js.

Community entries are indexed automatically and are not reviewed: read what an item does before you install it. Third-party items belong to their publishers.
