Install in a minute

Getting set up.

{{icon:windows}}

Windows

Run the installer and click Install. It installs just for you, with no admin prompt, and adds Start menu and desktop shortcuts.

If SmartScreen says "Windows protected your PC", click More info → Run anyway. The app isn't code-signed yet.

{{icon:terminal}}

Linux

Install the package. Your package manager pulls in WebKitGTK for you:

sudo apt install ./{{dl:_amd64:file}}

Using the tarball? Unpack it and run ./install.sh to add it to your app menu.

{{icon:command}}

macOS

Install Apple's free command line tools, then build:

xcode-select --install
./build_mac.sh

Drag the app from the new .dmg into Applications.

Terminal only · no setup

Terminal app & VS Code.

Only want the terminal? Install astro with one command, without the setup wizard or admin rights. It downloads the Clean edition from the official GitHub release, checks it against SHA256SUMS.txt, and puts astro on your PATH.

  • {{icon:linux}}Linux (x64) & macOScurl -fsSL https://esoexe.github.io/astro-ai/install.sh | sh
  • {{icon:windows}}Windows 10/11 in PowerShellirm https://esoexe.github.io/astro-ai/install.ps1 | iex

It goes into ~/.astro-ai (Windows: %LOCALAPPDATA%\Programs\AstroAI-CLI). Update with astro update (or run the same command again). To remove it: curl -fsSL https://esoexe.github.io/astro-ai/install.sh | sh -s -- --uninstall, or on Windows set $env:ASTRO_UNINSTALL="1" first. Read the scripts before running them: install.sh · install.ps1.

Package managers: Windows scoop bucket add astro-ai https://github.com/esoexe/astro-ai then scoop install astro-ai · macOS brew install --cask esoexe/tap/astro-ai · Linux brew install esoexe/tap/astro-ai

Every desktop download also includes astro, the agent for your terminal: astro in any folder, astro -p for scripts, and astro parallel to run several agents, each in an isolated copy. The .deb installs it as /usr/bin/astro. On Windows, Setup adds it to your PATH. How to use it →

Verify your download

Check it's the real thing.

Each file has a SHA-256 checksum listed above. Compare it with the file you downloaded. If they match, the file is exactly what we published.

Download SHA256SUMS.txt

Windows (PowerShell)

Get-FileHash .\{{dl:windows-x64-Setup:file}} -Algorithm SHA256

Linux

sha256sum -c SHA256SUMS.txt --ignore-missing

macOS

shasum -a 256 {{dl:macos-universal:file}}

Android

Phones check the signature for you: an update signed with a different key is refused. On a computer with the Android SDK you can also compare the certificate with the fingerprint in the Android card above:

apksigner verify --print-certs {{dl:-android-arm64.apk:file}}
About the "Clean" in the file names. Public downloads are the Clean edition, so they ship with no API keys at all. The app shows up as A.S.T.R.O AI Clean. It works straight away with 26 free models, and you can add your own free keys in Settings → Providers & keys to bring in more.
