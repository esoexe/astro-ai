1.2.0

LatestOctober 28, 2026

The Astro AI Library, tested code fixes, smarter model picking and safer builds.

Astro AI Library

  • A reviewed library of MCP servers, skills and plugins, in the website Console (no sign-in needed) and in the desktop app under Workspace › Extensions › Library
  • One-click install from the website with astroai:// links (Windows and Linux). The app always shows what an item does before you install it
  • Every file is checked against its SHA-256 fingerprint. Skills and plugins are plain text only, and MCP packages are pinned to exact versions
  • Tokens you type stay in the app on your computer. Local MCP servers no longer see Astro AI's own provider keys

Answers that work

  • Background code check: after a coding answer appears, Astro AI quietly compiles or runs the code (self-contained code only, 6 s limit). If it fails, a coder model fixes it, and the fix is added only if it passes. You can turn it off in Settings › Brain
  • Model picking learns from real results: models that keep failing or slowing down are moved back, and coding benchmark results raise the strongest coders
  • The Agent says clearly when it changed files without running a check, and stray "analysis…" text from some models no longer leaks into answers
  • 👎 now asks what went wrong. Your note is saved on your computer and shared with the team only if you tick Share
  • When the shared free limits run out, Astro AI explains this and offers a one-minute way to add your own free key

Builds and safety

  • Tests run on every push (GitHub Actions), with a secret scan and a check for private files
  • A ready-made macOS app: a universal .dmg built on GitHub's Macs (not notarized yet, so right-click › Open the first time). Windows and Linux builds are also made on GitHub Actions, with optional code signing. Only the Clean edition is ever built there
  • Fixed: the macOS server did not link (a declaration problem in the code runner). The new Mac build found it
  • Fixed: the source kit and the repository were missing a file (astro_dev.inc), so building from source failed in 1.1.1

1.1.1

October 28, 2026

Better code from the free models, plus agent fixes. New installers for Windows, Linux and macOS.

Coding quality

  • Astro AI now spots code questions by itself, in English, Arabic and French. They get Astro's coding standard: complete runnable code, only real APIs, edge cases checked, and secure defaults
  • Code answers use a low temperature, and long code is no longer cut off mid-file
  • For code, the team's lead, reviewers and merger are the strongest free coding models
  • The merge keeps one working draft as its base instead of stitching different drafts together. If the merge fails, the next coder retries
  • Agent fixes: tool calls sent together run one by one, the agent can't finish before it has seen its results, and empty file writes are refused
  • Open VSX themes show their real names

1.1.0

October 27, 2026

Astro AI becomes a full coding platform, with the features of OpenCode, Claude Code, Codex, Cursor, VS Code, Antigravity and DeepSeek Harness. See the features →

Projects

  • Open folder: work on any folder on your computer in place; closing it never deletes files
  • Agent permission modes: Plan (read-only), Ask (approve each change and command) and Auto. Opened folders start in Ask
  • Reads AGENTS.md, CLAUDE.md, GEMINI.md, Cursor rules and Copilot instructions

Agent

  • Slash commands: /init, /plan, /review, /test, /commit, /compact, /skills, /mcp, /agents, plus your own commands
  • New tools: glob, diagnostics, a live to-do list, skills, MCP tools and subagents
  • Hands sub-tasks to Claude Code, Codex, OpenCode, Gemini CLI or DeepSeek Harness when they are installed
  • Hooks run your scripts before and after tools; errors are checked automatically after each edit
  • Agent Manager shows every session at once
  • If a model only describes what it will do, the next model takes over

Extensions

  • MCP: add servers, browse the official registry and use project .mcp.json files (trusted first)
  • Plugins: install Claude Code plugins and marketplaces from GitHub
  • Themes and snippets from Open VSX
  • Skills from SKILL.md folders

Editor

  • Problems panel with live error squiggles
  • AI inline suggestions (ghost text) and Ctrl I inline edit
  • Snippet completions; fixed completion sources that could disappear while typing

Astro API

  • Paste your astro_sk_ key once to use every provider saved in your Astro account, with free failover

1.0.0

October 27, 2026

The first public release of the Astro AI desktop app. Read the announcement →

One Brain

  • Team answers: every available model plans, works, reviews and answers together as one
  • Progress card with Plan, Work, Review and Answer stages, plus Answer now
  • Each answer shows how many models contributed, the merging model, and team confidence
  • 26 free models out of the box, with more than 50 providers supported through your own free keys

Spaces

  • Workspace: editor, file tree, run code in 7 languages, live preview, terminal, versions and undo, AI engineering team with Team, Fast and Agent modes
  • Agent: autonomous jobs with logged steps, per-file diffs and checkpoints
  • Model Lab, Reader, Notes, Tasks, Knowledge files and a Calculator
  • Live voice conversation, dictation and read-aloud
  • General, Compare and Web modes, response language, Markdown export, command palette (Ctrl K)

Design

  • "Orbit" interface with light and dark themes, tabs, projects and sessions
  • A new app icon

Desktop

  • Native app for Windows (WebView2) and Linux (WebKitGTK), plus a macOS build kit that makes a universal app
  • A custom Windows installer: per-user, no admin prompt, silent mode, and a clean uninstall with an optional data purge
  • Debian package and portable builds for Windows and Linux
  • Local engine bound to 127.0.0.1 only. No telemetry.

Known limitations

  • Windows builds aren't code-signed yet, so SmartScreen shows a warning
  • No ready-made macOS download yet. Build it with the kit.
  • Free-tier limits are set by each provider and can change without notice
