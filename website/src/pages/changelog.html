1.5.0

LatestOctober 29, 2026

A full-screen terminal app, a redesigned desktop Agent page and a new icon.

Full-screen terminal app

  • astro now opens a full-screen app in the spirit of Claude Code and OpenCode: a calm conversation view, a status line, and a side panel with the project, mode, model, to-do list and changed files. The panel opens by itself on wide terminals; Ctrl+B toggles it
  • Approve changes right in the terminal in Ask mode (y once, a for the rest of the run, n no), and switch between Auto, Plan and Ask with Shift+Tab
  • A model picker (Ctrl+O), session resume (Ctrl+R), a live list of parallel agents (Ctrl+G) and a shortcuts overlay (?)
  • 23 slash commands, including /parallel "task" "task" --merge, /diff, /undo, /review and /mode. Alt+Enter or Ctrl+J adds a new line
  • Prefer the old line-by-line view? Use astro --classic or set ASTRO_TUI=0. Scripts using astro -p work exactly as before

Redesigned Agent page

  • Three columns: your sessions with live status, time, files changed and mode; the run in the middle; and a new Session panel on the right
  • The Session panel shows context used, the git branch and uncommitted files, the checkpoint with Undo all, the rules and skills in use, and usage for the run
  • Switch the project's trusted MCP servers on or off for the agent, right from the panel
  • Steps are shown as flat, readable rows. Each run ends with a one-line recap of what changed and whether the tests passed, still fail or weren't run, plus turn stats
  • Works in the light and dark themes and on small screens. The flat steps and the recap also appear in the Workspace's Agent mode

New icon

  • A refined orbit: a peach sphere with three orbits and four satellites, redrawn for every size from the 16 px favicon to the macOS dock

Fixes

  • Some models write their own tool-call markup (for example MiniMax and Hermes-style <tool_call> blocks). The agent now reads these as real tool calls and never shows the raw markup in its replies
  • The Session panel's git count refreshes as soon as files change, and "1 step" is no longer written as "1 steps"

1.4.1

October 28, 2026

A new name, a new website and a steadier agent engine.

Astro AI is now A.S.T.R.O AI

  • The name now says how it works: All Systems Thinking, Reasoning as One. All the models, using real tools, each think the problem through, reason over each other's work and give you one answer
  • Only the name changed. Your chats, projects, keys and settings stay where they were, updates install over the old version, and the astro command is the same
  • On a Mac, the new A.S.T.R.O AI Clean.app sits next to the old Astro AI Clean.app. They share the same data, so you can delete the old one after the first launch. If you linked astro before, run the new link command from the download page
  • A redesigned website that explains what the app is for, with real recordings of the terminal app

Terminal-only install

  • Install just the astro command, with no setup wizard and no admin rights: curl -fsSL https://esoexe.github.io/astro-ai/install.sh | sh on Linux and macOS, or irm https://esoexe.github.io/astro-ai/install.ps1 | iex in PowerShell
  • Downloads come from the official GitHub release and are checked against SHA256SUMS.txt. Run it again to update, or add --uninstall to remove it (your chats, settings and keys are kept)

Agent engine

  • 3-way merge. When you and an agent changed different parts of the same file, merging now combines both instead of stopping. Real conflicts are still shown and never overwritten
  • An agent must read an existing file before it can replace it with write_file, so it keeps your style, module system and code
  • If the last test or build command still fails, the result is marked Needs attention, and astro parallel --merge skips that agent instead of merging it
  • When a model keeps repeating the same failing step, the job moves to the next model
  • Understands more tool-call formats that some models write: GLM and Qwen <tool_call> markup, several calls opened in one block, name {args} and name(args), missing closing braces, and code fences inside file contents. Repaired calls are stored in the standard format, so the next model doesn't copy the mistake
  • Commands sent with the project's own name as the working folder now work inside isolated copies, and duplicate calls in one reply run once

1.4.0

October 28, 2026

A.S.T.R.O AI in your terminal, agents that run in the background and in parallel, a VS Code extension, project tools, an SDK and a benchmark.

Terminal app: astro

  • astro in any folder starts an interactive agent session, with /mode, /model, /review, /sessions, /diff, /undo and more. Ctrl+C stops the agent within about a second
  • astro -p "task" is for scripts and CI. Progress goes to stderr and the report to stdout. --json prints one event per line, and the exit codes are 0 done, 1 error, 2 stopped, 3 paused
  • Plan, Ask and Auto modes work in the terminal too. In Ask mode you approve each change inline. With no one watching, changes are blocked instead of waiting forever
  • Included in every desktop download. The .deb installs /usr/bin/astro and Windows Setup adds it to your PATH. When the app is closed, astro starts the app's engine itself

Background and parallel agents

  • A new agent engine runs agents inside the A.S.T.R.O AI server, so they keep working when you close the window. Up to 8 run at once, and the rest wait in a queue
  • Isolated copies. Each parallel agent works in its own git worktree, including your uncommitted and untracked files, or in a copy of the folder. Your project is untouched until you merge
  • Safe merge. Review the diff, then merge or discard. Merging stops when a file was also changed in the project after the agent started. You can merge the rest, or apply the agent's version. Every merge can be undone
  • In the app: the Parallel chip on the Agent page. In the terminal: astro parallel "A" "B" --merge, astro agents, astro diff, astro merge

For developers

  • VS Code extension (.vsix, also for VSCodium, Cursor and Windsurf). It can run the agent on the open folder or the selection, run parallel agents, follow, diff, merge and undo
  • Project tools. JSON files in .astro/tools/ give the agent your own commands, with shell-quoted arguments. Plan and Ask modes apply to them too
  • Engine HTTP API and JavaScript SDK (sdk/js) to drive agents from your own tools
  • Benchmark (bench/): 12 small repository tasks with hidden checks, in JavaScript, C, shell, HTML and JSON. Each check is proven to fail before a change and pass on a reference solution
  • First run, with the default choice of free models: 12 of 12 tasks passed, averaging 40 s and 4 steps per task. That was one run on one day, and results change as free models change. node bench/run.js runs it yourself

1.3.0

October 28, 2026

The Library now lists every MCP server, agent skill, plugin and AI tool we can index, and the Console moved to /profile.

The whole ecosystem in the Library

  • Every server in the official MCP Registry (50,000+), plus thousands of agent skills and Claude Code plugins from public GitHub repos and marketplaces
  • AI tools: command-line coding agents and helpers from npm and PyPI that install in one click, and a directory of thousands of AI apps and sites collected from open awesome lists
  • The catalog rebuilds itself every day. Filter by kind, search everything, or tick Reviewed only to see just the items the A.S.T.R.O AI team checked
  • Community items are labelled with their source and install with one click. The same rules still apply: MCP packages are pinned to exact versions, skills and plugins are pinned to a git commit and every file is checked against its SHA-256, and hooks, binaries and local plugin servers are never installed
  • Installed AI tools get their own folder. Only the commands they declare are added to the agent's and terminal's PATH, so they never replace programs you already have

Website

  • The Console now lives at /profile. Old account.html links still work and keep their page (for example #library)
  • Fixed: the "Open in A.S.T.R.O AI" button in the Library had invisible text

1.2.0

October 28, 2026

The A.S.T.R.O AI Library, tested code fixes, smarter model picking and safer builds.

A.S.T.R.O AI Library

  • A reviewed library of MCP servers, skills and plugins, in the website Console (no sign-in needed) and in the desktop app under Workspace › Extensions › Library
  • One-click install from the website with astroai:// links (Windows and Linux). The app always shows what an item does before you install it
  • Every file is checked against its SHA-256 fingerprint. Skills and plugins are plain text only, and MCP packages are pinned to exact versions
  • Tokens you type stay in the app on your computer. Local MCP servers no longer see A.S.T.R.O AI's own provider keys

Answers that work

  • Background code check: after a coding answer appears, A.S.T.R.O AI quietly compiles or runs the code (self-contained code only, 6 s limit). If it fails, a coder model fixes it, and the fix is added only if it passes. You can turn it off in Settings › Brain
  • Model picking learns from real results: models that keep failing or slowing down are moved back, and coding benchmark results raise the strongest coders
  • The Agent says clearly when it changed files without running a check, and stray "analysis…" text from some models no longer leaks into answers
  • 👎 now asks what went wrong. Your note is saved on your computer and shared with the team only if you tick Share
  • When the shared free limits run out, A.S.T.R.O AI explains this and offers a one-minute way to add your own free key

Builds and safety

  • Tests run on every push (GitHub Actions), with a secret scan and a check for private files
  • A ready-made macOS app: a universal .dmg built on GitHub's Macs (not notarized yet, so right-click › Open the first time). Windows and Linux builds are also made on GitHub Actions, with optional code signing. Only the Clean edition is ever built there
  • Fixed: the macOS server did not link (a declaration problem in the code runner). The new Mac build found it
  • Fixed: the source kit and the repository were missing a file (astro_dev.inc), so building from source failed in 1.1.1

1.1.1

October 28, 2026

Better code from the free models, plus agent fixes. New installers for Windows, Linux and macOS.

Coding quality

  • A.S.T.R.O AI now spots code questions by itself, in English, Arabic and French. They get Astro's coding standard: complete runnable code, only real APIs, edge cases checked, and secure defaults
  • Code answers use a low temperature, and long code is no longer cut off mid-file
  • For code, the team's lead, reviewers and merger are the strongest free coding models
  • The merge keeps one working draft as its base instead of stitching different drafts together. If the merge fails, the next coder retries
  • Agent fixes: tool calls sent together run one by one, the agent can't finish before it has seen its results, and empty file writes are refused
  • Open VSX themes show their real names

October 27, 2026

The first public release of the A.S.T.R.O AI desktop app. Read the announcement →

One Brain

  • Team answers: every available model plans, works, reviews and answers together as one
  • Progress card with Plan, Work, Review and Answer stages, plus Answer now
  • Each answer shows how many models contributed, the merging model, and team confidence
  • 26 free models out of the box, with more than 50 providers supported through your own free keys

Spaces

  • Workspace: editor, file tree, run code in 7 languages, live preview, terminal, versions and undo, AI engineering team with Team, Fast and Agent modes
  • Agent: autonomous jobs with logged steps, per-file diffs and checkpoints
  • Model Lab, Reader, Notes, Tasks, Knowledge files and a Calculator
  • Live voice conversation, dictation and read-aloud
  • General, Compare and Web modes, response language, Markdown export, command palette (Ctrl K)

Design

  • "Orbit" interface with light and dark themes, tabs, projects and sessions
  • A new app icon

Desktop

  • Native app for Windows (WebView2) and Linux (WebKitGTK), plus a macOS build kit that makes a universal app
  • A custom Windows installer: per-user, no admin prompt, silent mode, and a clean uninstall with an optional data purge
  • Debian package and portable builds for Windows and Linux
  • Local engine bound to 127.0.0.1 only. No telemetry.

Known limitations

  • Windows builds aren't code-signed yet, so SmartScreen shows a warning
  • No ready-made macOS download yet. Build it with the kit.
  • Free-tier limits are set by each provider and can change without notice
