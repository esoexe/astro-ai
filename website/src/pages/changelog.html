1.8.1 · Android 1.8.2

LatestOctober 30, 2026

Use A.S.T.R.O AI on your computer from your phone: pair once with a QR code.

Phone access (desktop and terminal)

  • Settings → Phone: turn on Let my phone connect, click Pair a phone, and scan the QR code with your phone. The phone then uses this computer's models, keys, chats and projects.
  • Off by default. Only devices on a private network (same Wi-Fi, or Tailscale) can connect, and only after pairing. A code works once and expires after 10 minutes. Each phone gets its own key; remove any phone at any time.
  • From a terminal: astro phone pair draws the QR code right in the terminal; /phone works in the full-screen app too.

Android 1.8.2

  • Pair with the desktop app: scan its QR code, or type the address and the 8-digit code. The app always shows which computer it is about to connect to and waits for you to tap Connect.
  • Reconnect and Forget this computer. Switching to the phone's own engine keeps the pairing, so you can switch back without a new code.
  • A clear message when the computer has removed the phone, instead of a sign-in screen.

Good to know

  • Traffic stays inside your network but is not encrypted, so use it on networks you trust (home Wi-Fi, Tailscale), not on public Wi-Fi. A paired phone can do what the app can do on that computer, including running code in your projects, so pair only your own phones.
  • The first time, Windows or macOS may ask whether A.S.T.R.O AI may accept connections: allow it on private networks.
  • Tested end to end in test environments (pairing, reconnect, forget, wrong codes, removed phones), not yet on many real phones and networks. Please tell us how it works for you.

Android onlyOctober 30, 2026

The Android app is rebuilt as a real native app. Desktop apps stay on 1.8.0; nothing changes for them.

Native app

  • Written in Kotlin with Jetpack Compose. No web page inside an app any more: screens, gestures, the keyboard, Back and dark mode behave like any Android app.
  • Everything is there: chat with One Brain, compare models, live voice, notes, tasks, reminders, memory, reader, knowledge files, calculator, model lab, the Workspace (files, editor, terminal, search, checkpoints, Git, ZIP) and the Agent with approvals, changes, merge and undo.
  • Reminders are real Android notifications and survive a restart. Long answers and agent runs keep going while you use other apps.
  • Share text, links, photos or PDFs to A.S.T.R.O AI from any app.
  • English, French and Arabic (right-to-left), following the phone's language or your choice.

Fixes

  • Chats and settings are now kept when the app restarts. In 1.8.0 they could be lost on every restart. Provider keys and projects saved in 1.8.0 carry over.

New

  • In-app updates from this site, checked against the SHA-256 published here and the app's signing key.

Good to know

  • The 1.8.0 app can't tell you about this update. Install the new APK over it from the download page.
  • Tested on a computer, not yet on many real phones: the engine under arm64 emulation, and every screen (light, dark and Arabic) opened in an Android test environment against a real engine. Please tell us how it runs.

1.8.0

October 30, 2026

An Android app with the engine inside, an Agent that gives the honest answer the first time, opt-in error reports and feedback, an offline natural voice, ARM64 builds, and an accessibility pass.

Android app (new)

  • The same engine as the desktop app runs inside the app, on your phone: chats, One Brain, the Workspace, the Agent, notes and settings. Android 8.0 or newer, 64-bit ARM
  • Only the app can use its engine. Each start makes a new random key that only the app's own window gets, so other apps on the phone are refused even though the engine listens on 127.0.0.1
  • Voice input and read-aloud use your phone's own speech services. Saved files go to Downloads/A.S.T.R.O AI. "Share" text from any app straight into the chat box
  • Two permissions only: internet, and the microphone (asked the first time you use voice). No cloud backup of your data
  • Signed APK on the download page, with its SHA-256 and the signing certificate's fingerprint. Not on Google Play yet
  • Honest status: built and tested on a computer (the engine under arm64 emulation, the app's voice, files and links in a browser with a stand-in for the phone), not yet on many real phones. Please tell us how it runs

The Agent: honest the first time, the whole job at once

  • No more "100% complete" followed by "actually, not complete" when you push. A finished-job report that claims more than the job's own checks prove is sent back: the Agent must run the build and tests and confirm each requirement, or rewrite the report as a calibrated status (verified, not verified, missing)
  • Questions like "is it done?", "what's missing?" or "be honest" make the Agent inspect the real files and run the checks before answering, instead of answering from memory
  • It doesn't flip its answer just because you push back. If new evidence shows it was wrong, it says what was wrong and why. If it was right, it keeps the answer and explains it
  • It does the whole job in one run: no stubs or "TODO: implement" left behind, and no stopping halfway to ask whether to continue

Faster-feeling answers (One Brain stays the default)

  • While the team works you see its steps (Plan, Work, Review, Answer) and an honest time estimate based on your last answers, instead of an open-ended spinner
  • Local only (Settings › Brain): answer only with models on your own computer through Ollama. Private, works offline, slower on most PCs

Feedback, reports and first run

  • Send feedback from the menu: a short form, sent only when you press Send
  • Anonymous error reports, off by default. Turn them on in the welcome screen or Settings › Data & privacy. Only errors and engine crashes, with keys, tokens, e-mail addresses and personal paths removed. Never chats, files or prompts
  • A simpler first run: a short welcome screen and a Simple menu that shows the main things first (everything else is one tap away)
  • New pages: Beta testing, What it can't do (yet), Support the project, and an updated privacy page. New SECURITY.md with how to report a vulnerability privately
  • A.S.T.R.O AI Pro: only the plumbing for now (a license check and a waitlist). Nothing is for sale and nothing in the app is locked

Natural voice (offline)

  • Settings › Voice › Natural voice: a neural voice (Piper) that runs on your computer, works offline and sounds much better than most system voices. English, French and Arabic. Downloads are checked against pinned SHA-256 hashes
  • Voice credits: the French voice "siwis" is based on the SIWIS dataset (CC BY 4.0). The Arabic voice "kareem" has no stated dataset license, so it is offered for personal use only. The English voices are public domain or CC0

Agent sandbox

  • Settings › Data & privacy › Agent sandbox (Linux, off by default): every Agent command runs in an operating-system sandbox (bubblewrap). Only the project folder can be changed; your home folder, keys and other files are hidden. Internet inside the sandbox is optional

ARM64 builds

  • Windows on ARM (Snapdragon PCs) and Linux arm64 (Raspberry Pi 4/5 with a 64-bit OS, ARM laptops and servers) get native builds. The Windows ARM64 build needs Windows 11 on ARM
  • Honest status: built, not tested on real ARM devices yet. On Windows 11 ARM the normal x64 installer also works (emulated)
  • install.sh and install.ps1 pick the ARM64 build automatically on ARM machines, and the in-app updater downloads the right one

Accessibility and fixes

  • Every settings switch and menu has a proper label for screen readers. The Workspace tabs work with the keyboard (arrows, Enter, Delete to close). Dialogs keep the focus inside and give it back when they close
  • Higher contrast for small grey text, teal buttons and file-type badges, in light and dark themes (WCAG AA). Checked with axe-core on every main screen
  • MCP servers you started are now stopped when A.S.T.R.O AI closes or its engine stops

1.7.0

October 29, 2026

A more reliable agent, automatic updates, faster first answers, easy free keys, safer plugins and commands, and French and Arabic.

A more reliable agent

  • Fixed empty file writes from models that send tool arguments as a JSON string (such as gpt-oss). The file content now arrives intact
  • The agent never replaces a file with empty content. If a model keeps sending empty writes, or stops after failed steps, the next model takes over with a short handover note
  • More argument spellings are understood (file_text, old_string/new_string), and an intentionally empty replacement stays empty
  • A run is only marked done after the changed files have been checked. If every file change failed, it is shown as Needs attention instead of done, and the terminal app exits with code 4
  • Leaked model reasoning text is hidden on the Agent page as well as in chat

Automatic updates

  • The app checks for a new version (at most every 6 hours; no personal data is sent) and shows a banner with what's new
  • Update now downloads the installer from the official site and checks its SHA-256 before using it. On Windows it installs quietly and restarts the app; on macOS and Linux it opens the disk image or package for you
  • Terminal installs: astro update (or astro update --check). Settings › General has a Check now button
  • The Windows terminal installer no longer fails with "Access denied" when A.S.T.R.O AI is running: it closes it first, and moves locked files out of the way

Faster first answer

  • In One Brain mode, the fastest model's answer appears within seconds while the whole team keeps working. It is then replaced by the merged team answer. Turn it off in Settings › Brain › Show the fastest answer first

More free models in a minute

  • A new Get more free models card (Settings › Providers, or /free-keys in chat) walks you through free keys from Groq, OpenRouter, Mistral and Cohere: open the sign-up page, paste the key, done. It shows how many models each key adds and tests the key as soon as you paste it
  • Free tiers have daily limits that the providers set; extra keys give you more room, not unlimited use

Model health

  • Models that a provider has removed or renamed are skipped for 24 hours instead of failing again and again, and they are checked again later. This is saved across restarts

Safer by default

  • The agent asks before risky commands, in Auto mode too: sudo, piping a download into a shell, deleting whole folders such as your home or drive, force-pushing, formatting disks, shutting down, editing the Windows registry or publishing packages. Choose Allow, Allow all in this run, or Deny. Runs with nobody to ask are blocked and told why. Everyday commands such as rm -rf node_modules are not affected. Set ASTRO_ALLOW_RISKY=1 to turn this off
  • Before a plugin is installed, A.S.T.R.O AI shows what it can do: run commands automatically (hooks), start programs (MCP servers), include scripts, or only add text and settings. Nothing is installed until you agree

Problem reports

  • When something breaks, a small notice offers Report it. It opens a GitHub issue form filled in with your version, system and the last errors, scrubbed of keys, email addresses and your user name. You read it and send it yourself; nothing is sent automatically
  • Also in Settings › General › Report a problem, and astro bug in the terminal
  • New: GitHub Discussions for questions, ideas and show and tell

Languages

  • The app's menus and buttons are now available in French and Arabic (right-to-left), picked from your system language or in Settings › General › Interface language. Code, file names and your own text are never translated. Answers follow the separate Response language setting

Install with a package manager

  • Windows (Scoop): scoop bucket add astro-ai https://github.com/esoexe/astro-ai then scoop install astro-ai
  • macOS (Homebrew): brew install --cask esoexe/tap/astro-ai. Linux (Homebrew): brew install esoexe/tap/astro-ai

Coding benchmark

  • New results from our small 12-task coding benchmark, run with free models only, are on the docs page, including what failed

1.4.1

October 28, 2026

A new name, a new website and a steadier agent engine.

Astro AI is now A.S.T.R.O AI

  • The name now says how it works: All Systems Thinking, Reasoning as One. All the models, using real tools, each think the problem through, reason over each other's work and give you one answer
  • Only the name changed. Your chats, projects, keys and settings stay where they were, updates install over the old version, and the astro command is the same
  • On a Mac, the new A.S.T.R.O AI Clean.app sits next to the old Astro AI Clean.app. They share the same data, so you can delete the old one after the first launch. If you linked astro before, run the new link command from the download page
  • A redesigned website that explains what the app is for, with real recordings of the terminal app

Terminal-only install

  • Install just the astro command, with no setup wizard and no admin rights: curl -fsSL https://esoexe.github.io/astro-ai/install.sh | sh on Linux and macOS, or irm https://esoexe.github.io/astro-ai/install.ps1 | iex in PowerShell
  • Downloads come from the official GitHub release and are checked against SHA256SUMS.txt. Run it again to update, or add --uninstall to remove it (your chats, settings and keys are kept)

Agent engine

  • 3-way merge. When you and an agent changed different parts of the same file, merging now combines both instead of stopping. Real conflicts are still shown and never overwritten
  • An agent must read an existing file before it can replace it with write_file, so it keeps your style, module system and code
  • If the last test or build command still fails, the result is marked Needs attention, and astro parallel --merge skips that agent instead of merging it
  • When a model keeps repeating the same failing step, the job moves to the next model
  • Understands more tool-call formats that some models write: GLM and Qwen <tool_call> markup, several calls opened in one block, name {args} and name(args), missing closing braces, and code fences inside file contents. Repaired calls are stored in the standard format, so the next model doesn't copy the mistake
  • Commands sent with the project's own name as the working folder now work inside isolated copies, and duplicate calls in one reply run once

1.4.0

October 28, 2026

A.S.T.R.O AI in your terminal, agents that run in the background and in parallel, a VS Code extension, project tools, an SDK and a benchmark.

Terminal app: astro

  • astro in any folder starts an interactive agent session, with /mode, /model, /review, /sessions, /diff, /undo and more. Ctrl+C stops the agent within about a second
  • astro -p "task" is for scripts and CI. Progress goes to stderr and the report to stdout. --json prints one event per line, and the exit codes are 0 done, 1 error, 2 stopped, 3 paused
  • Plan, Ask and Auto modes work in the terminal too. In Ask mode you approve each change inline. With no one watching, changes are blocked instead of waiting forever
  • Included in every desktop download. The .deb installs /usr/bin/astro and Windows Setup adds it to your PATH. When the app is closed, astro starts the app's engine itself

Background and parallel agents

  • A new agent engine runs agents inside the A.S.T.R.O AI server, so they keep working when you close the window. Up to 8 run at once, and the rest wait in a queue
  • Isolated copies. Each parallel agent works in its own git worktree, including your uncommitted and untracked files, or in a copy of the folder. Your project is untouched until you merge
  • Safe merge. Review the diff, then merge or discard. Merging stops when a file was also changed in the project after the agent started. You can merge the rest, or apply the agent's version. Every merge can be undone
  • In the app: the Parallel chip on the Agent page. In the terminal: astro parallel "A" "B" --merge, astro agents, astro diff, astro merge

For developers

  • VS Code extension (.vsix, also for VSCodium, Cursor and Windsurf). It can run the agent on the open folder or the selection, run parallel agents, follow, diff, merge and undo
  • Project tools. JSON files in .astro/tools/ give the agent your own commands, with shell-quoted arguments. Plan and Ask modes apply to them too
  • Engine HTTP API and JavaScript SDK (sdk/js) to drive agents from your own tools
  • Benchmark (bench/): 12 small repository tasks with hidden checks, in JavaScript, C, shell, HTML and JSON. Each check is proven to fail before a change and pass on a reference solution
  • First run, with the default choice of free models: 12 of 12 tasks passed, averaging 40 s and 4 steps per task. That was one run on one day, and results change as free models change. node bench/run.js runs it yourself

  • "Orbit" interface with light and dark themes, tabs, projects and sessions
  • A new app icon

Desktop

  • Native app for Windows (WebView2) and Linux (WebKitGTK), plus a macOS build kit that makes a universal app
