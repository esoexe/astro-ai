How One Brain works

Not a router. A team.

Most multi-model apps send each question to one model. Astro AI asks every available model, has them check each other's work, then merges the best of it into a single answer.

01

Plan

The team reads your question, your chat history and any knowledge files, then agrees on an approach.

02

Work

Every available model drafts its own answer at the same time. Slow models still get a say.

03

Review

The drafts are compared. Where models disagree, the team finds the reason and checks facts and code.

04

Answer

One model merges the best parts into a single reply, and shows how many models contributed and how confident they were.

Honest by design

Teamwork takes a few minutes.

Waiting for every mind is slower than asking one. A full One Brain answer usually takes a few minutes, and Astro AI shows each stage while it works. Press Answer now at any time to stop waiting for slower teammates.

  • Need it fast? Pick any single model, or use Fast mode in the Workspace.
  • Every answer shows how many models worked on it and which model merged it.
  • Free tiers have daily limits. When one provider runs out, the rest of the team carries on.

Questions

Good to know.

Is Astro AI really free?

Yes. The app is free, and so are the models it uses out of the box. They come from providers' free tiers, which have daily or per-minute limits. When one provider hits its limit, the rest of the team keeps going.

You can add free API keys from more providers in Settings. Nothing in Astro AI asks you to pay.

Do I need an account?

No. There is no Astro AI account and no sign-in. Install it and start chatting. Some providers ask you to sign up to get a free key, but that's optional.

Where do my chats go?

Chats, notes, tasks, projects and keys are stored on your computer. When you ask a question, the text goes to the AI providers that answer it, and each provider has its own privacy policy. Astro AI has no analytics and no telemetry. Read the privacy page.

Why is a One Brain answer slower than other chatbots?

Because it waits for the whole team, then reviews and merges their answers. That usually takes a few minutes. You can press Answer now at any time, or pick a single model for quick replies.

Is this AGI?

No. Astro AI combines existing language models, and teamwork tends to catch more mistakes than any one model alone. But the models can still be wrong, so double-check anything important.

Windows says it "protected my PC". Is that safe?

The installer isn't code-signed yet, so Microsoft SmartScreen shows a warning for new apps. Click More info, then Run anyway. To be sure the file wasn't changed along the way, compare its SHA-256 checksum with the one on the download page.

Does it work offline?

The editor, notes, tasks and calculator work offline, and so does running code with compilers you have installed. AI answers need an internet connection, because the models run in the cloud.
