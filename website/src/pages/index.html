      01 / What it's for
      
What is A.S.T.R.O AI for?

      
One app for the things people use AI for every day, with a whole team of free models behind every answer. No subscription, no sign-in.

    

    

      

        
{{icon:chat}}

        
Ask & learn

        
Questions, explanations, research, writing and maths. Many models draft, check each other, and you get one clear answer. Talk to it with the voice button.

{{icon:code}}

        
Build software

        
Open a folder. The agent reads your code, plans, writes, runs the tests and shows you a diff. You choose Plan, Ask or Auto, and every run can be undone.

      02 / How it works
      
Five letters, one idea.

      
The name is the method. Every question and every coding job goes through the same five steps.

    

    
    
      
  1. AAll models
    Every free model you have access to joins in, including the slow ones. Free tiers have limits; when one provider is busy, the rest carry on.
    2. 
      
  2. SSystems
    The team can use real tools: your files, a terminal, web search, a code runner, MCP servers and skills.
    3. 
      
  3. TThinking
    Each model works on its own draft or plan, at the same time, so you see different approaches, not one guess.
    4. 
      
  4. RReasoning
    The drafts are compared and reviewed. A mistake one model makes is usually caught by another.
    5. 
      
  5. OOne answer
    You get one clear answer, or one finished change with a diff. Press Answer now if you don't want to wait.
    6.

      04 / Parallel agents
      
Three jobs, three copies, one project.

      
Each agent gets its own git worktree, or a copy if the folder isn't a git repo. They work side by side and can't break each other's work. When they finish, you review and merge.

      
    
        
  • Up to 8 agents at once, from the terminal or the Parallel panel
    • 
        
  • Edits to different parts of the same file are combined automatically
    • 
        
  • Real conflicts are shown to you and never overwritten
    • 
        
  • Every merge saves a checkpoint, so astro undo takes it back
    •

      06 / Permissions
      
You decide how much it can touch.

      
Every folder you open has a permission mode. Change it any time from the composer or with /mode. A checkpoint is saved before each run, so you can undo the whole job.

    

    

      

        
{{icon:eye}} Plan
Look, don't touch.
Read-only. The agent explores, searches and runs safe commands, then hands you a plan to approve.


› /plan add rate limiting
  read   src/server.js
  search app.use
  ✎ Plan · 4 steps
  write  src/limit.js  blocked
  Run this plan

      

      

        
{{icon:shield}} AskDefault for folders
Ask before changes.
Reading is free. Writing files and running commands waits for your OK, once or for the whole run.


› add rate limiting
  ✓ read src/server.js
  ? Write src/limit.js (15 lines)
  AllowAllow all this runDeny
  ✓ wrote src/limit.js
  ✓ edited src/server.js  +2

      

      

        
{{icon:zap}} Auto
Full speed.
The agent works on its own, logs every step and keeps a checkpoint, so one click undoes everything.


› add rate limiting
  ⟲ checkpoint saved
  ✓ wrote  src/limit.js
  ✓ edited src/server.js
  ✓ npm test · 14 passed
  ✓ team review done
  ↶ Undo all

      10 / Questions
      
Good to know.

    

    

      
Is A.S.T.R.O AI really free?

        
Yes. The app is free, and so are the models it uses out of the box. They come from providers' free tiers, which have daily or per-minute limits. When one provider hits its limit, the rest of the team keeps going.

        
You can add free API keys from more providers in Settings. Nothing in A.S.T.R.O AI asks you to pay.

      
What does A.S.T.R.O stand for?

        
All Systems Thinking, Reasoning as One. It describes how the app works: all the models, using real tools (systems), each think the problem through, reason over each other's work, and come back with one answer.

        
The terminal command is still astro, and so are the file and folder names.

      
Who is it for?

        
Anyone who wants a capable AI without paying for one: students, developers, makers and small teams. Use it to ask and learn, to build and fix software, or to run coding jobs from your terminal and scripts. The models run in the cloud, so it works well on older computers too.

      
It used to be called Astro AI. Did anything else change?

        
Only the name. Your chats, projects, keys and settings stay where they were, updates install over the old version, and the astro command works the same way. On a Mac, the new app sits next to the old one, so you can delete “Astro AI Clean” after the first launch.

      
Is it safe to let the agent work in my own folders?

        
Folders you open start in Ask mode: the agent can read, but every file change and command waits for your approval. Plan mode is read-only. In Auto the agent works on its own, but a checkpoint is saved first so you can undo the whole run.

        
It's still an AI, so review changes before you ship them, and keep your work in git.

      
Can I use my Claude Code, Cursor or OpenCode setup?

        
Yes. A.S.T.R.O reads AGENTS.md, CLAUDE.md and other rule files, skills, slash commands, subagents, hooks and MCP configs from the places those tools use, and installs Claude Code plugins from GitHub. If the CLIs are installed, the agent can also hand work to them.

      
Do MCP servers and plugins run automatically?

        
No. MCP servers from a project's config and project hooks only run after you trust them, because they can run code on your computer. You can stop or untrust them at any time in the Extensions panel.

      
Do I need an account?
Not for the app. There's no sign-in: install it and start. An account is optional and only needed for the A.S.T.R.O API.

      
Where does my code go?

        
Your projects, chats and keys stay on your computer. When you ask for something, the relevant text and code go to the AI providers that answer it, and each provider has its own privacy policy. A.S.T.R.O AI has no analytics and no telemetry. Read the privacy page.

      
Why does the agent take a while to finish?

        
After the work is done, the whole team reviews it, which can take a few minutes. Press ■ to skip the review, or switch the composer to Fast for quick single-model replies.

      
Is this AGI?

        
No. A.S.T.R.O AI combines existing language models, and teamwork tends to catch more mistakes than any one model alone. But the models can still be wrong, so double-check anything important.

      
Windows says it "protected my PC". Is that safe?

        
The installer isn't code-signed yet, so Microsoft SmartScreen shows a warning for new apps. Click More info, then Run anyway. To be sure the file wasn't changed along the way, compare its SHA-256 checksum with the one on the download page.
