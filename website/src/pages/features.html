01 / Coding platform

Bring your tools, skills and servers.

The features you know from OpenCode, Claude Code, Codex, Cursor, VS Code, Antigravity and DeepSeek Harness, in one app. A.S.T.R.O reads the setup files those tools already use, so an existing project works as it is.

How it works →

Open any folder on your computer. The editor, terminal, Git and agent work on your real files. Closing the folder never deletes anything.

{{icon:shield}}

Plan, Ask, Auto

Choose how much the agent may do: inspect and plan only, ask before each change and command, or work on its own. A checkpoint is saved before every run.

{{icon:command}}

Slash commands

/init, /plan, /review, /test, /commit, /compact and more, plus your own commands with $ARGUMENTS.

{{icon:bot}}

Subagents & CLIs

The agent can hand a sub-task to a subagent, or to Claude Code, Codex, OpenCode, Gemini CLI or DeepSeek Harness if you have them installed.

Agent Manager

An Antigravity-style view of every agent session in the window. Run jobs in parallel across projects and stop any of them.

Terminal app

A VS Code extension (also for VSCodium, Cursor and Windsurf) drives the same agents. Projects can add their own agent tools in .astro/tools.

02 / Workspace

A code editor with a team inside.

Open a project and the AI engineering team works right in your files. It reads a live index of the project, its memory, git status and terminal, then writes complete files, installs packages, runs the result and fixes failures.

  • Run JavaScript, Python, C, C++, Java, Bash and HTML/CSS with one shortcut
  • Output, live preview and a real terminal in the same window
  • Every change is saved as a version first, so you can diff it or undo it
  • Problems panel with live error squiggles, from node, tsc, gcc, cargo, go and more
  • AI ghost-text completions and Ctrl I inline edits
03 / Agent

Hand over the whole job.

Describe what you want built, fixed, researched or tested. The team of models plans the work and reviews it. A fast model carries out each step: it runs commands, writes and edits files, searches the web, starts servers and checks the results.

  • Three permission modes: Plan (read-only), Ask (you approve each change and command) and Auto
  • Slash commands, a live to-do list, subagents, skills and MCP tools
  • Every step is logged, with a diff for every file it touches and a one-line recap at the end
  • A Session panel with context used, git status, rules and skills in use, MCP switches and turn stats
  • A checkpoint before each job, so you can roll everything back
The agent can run commands on your computer. Folders you open start in Ask mode, so nothing changes without your approval. Keep backups of anything important.
Ask mode

Nothing runs without a yes.

Allow once, allow for the whole run, deny, or tell the agent what to do instead.

04 / Extensions

One panel for everything you plug in.

05 / One Brain

Every model, one answer.

Choose One Brain and your question goes to the whole team. Each model drafts an answer. The team reviews the drafts against each other, then one model merges them into a single reply.

  • Works out of the box with 26 free models. Add keys and the team grows.
  • Each answer shows how many models contributed, which one merged it, and how confident the team is
  • Press Answer now to stop waiting for slower teammates
  • Prefer one voice? Pick any single model from the list
06 / Model Lab

Put models head to head.

Send the same prompt to as many models as you like and compare their speed and answers side by side. Use it to find a favourite, or to check a tricky answer. Then export the results.

  • Quick picks: the fastest 4, any 8, or every ready model
  • Filter by name and spot vision-capable models at a glance
